# Introduction

This library is source generated for WebApi project in `Perigon Framework`.

- generate the extension methods for add `Managers` and `Modules`.
- discover `RestEndpointBase` endpoint groups and generate `MapEndpointGroups()` for Minimal API services.
- generate Localizer const keys for `IStringLocalizer` usage.

- generate enum-meta.generated.xml for SDK Web projects and their project references using an MSBuild task; the file is embedded and copied to build and publish output for consumption by OpenAPI and other tools.
